# TFLite Schema Binding

This directory contains the generated Python FlatBuffer binding copied from the pinned TensorFlow Lite Micro submodule.

The generated file is not edited manually.

Synchronize it with:

```bash
python3 scripts/generate_tflite_bindings.py
```

The source file is:

```text
third_party/tflite-micro/tensorflow/lite/python/schema_py_generated.py
```
